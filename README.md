# `.github`

Este repositorio existe para una sola cosa: **`profile/README.md`**, que es lo
que GitHub muestra en [la portada de la organización](https://github.com/legiosai).

Nada más vive acá. La bitácora de Legios —decisiones, handoffs, contratos— está
en un repositorio privado aparte, y no en éste, porque para que GitHub renderice
la portada este repositorio tiene que ser **público**, y la historia de git es
para siempre: cualquier cosa que entre acá queda a la vista aunque después se
borre.
